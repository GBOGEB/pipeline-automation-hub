**What JADE owns:** an index and navigation standard, source-pinned per-repo readiness/technical TODO, an evidence graph/federated read-only lens, a deterministic static dashboard, and a packaged Pages child via an already authorized publisher. **Not** security exception, admin rules, domain compliance/engineering accept, native CI gate relaxation, releases, merges or remote worker dispatch.

## ANALYZE — frontiers, risk concentrations and causal qualification

1. **Structure first:** 706 root suggestions are noncanonical placement candidates, not bugs. ABACUS 368, `cryo_leak_rate_dashboard` 115, CODEX 82 and DOCX_RTM_Automation 62 sum to **627/706 (~88.8%)** of heuristic reviews. Triage via KEEP, LINK_ALIAS_FIRST, MOVE_WITH_CONSUMER_REPLAY, ARCHIVE_PRESERVE_LINKS and OWNER_WAIT; prohibit bulk deletion. Same-stem HTML/PDF/DOCX are document families until proven redundant.
2. **Governance risk:** ABACUS has `protected=true` without demonstrated effective reviewer/check rules; most others `protected=false` in readbacks. This is a configuration observation, not an automated permission grant. Prioritise admin-held blocked-RED canary and eligible last-push review.
3. **Green survivorship:** sampled positive workflows (e.g. gg_MATH provider-proof; DOCX admission-policy; QPS census) form replay candidates. Green labels must retain `{repo, PR, head, run, attempt, check_id, completed_at, config, comparator}` and P0 owner sign-off before promotion to release readiness.
4. **Unknown cannot become green:** eight JADE owners were outside the historical GoGREEN roster; five of 41 sampled PRs lacked positive evidence in that separate census. Empty Actions query results and skipped checks are **UNKNOWN**, never successes.
5. **Pages != release:** `pages_portal.py` and the existing `code-purple-method-atlas.yml` already own publication. JADE is a hashed child at `/jade/green.html`, using *one* publisher and one reference manifest. No hosted URL was re-read and compared in this wave.
6. **Third-party/upstream-derived repositories:** Prettier, GitHub CLI, Python SDK, VS Code PowerShell and other imported copies need a **role/applicability** decision before a heavy bespoke workflow, policy or hosted Pages requirement is imposed.

### Positive/negative paired observation contract

Each GoGREEN capability record records behavior and expected successful condition, the observed test/check evidence, matched failure or fault-injection control, config/instrumentor, source SHA, and evidence lifetime. A historical green replay on a new head is credited only if (1) the same intended behavior and eligible input basis apply, (2) terminal native check provenance is bound, and (3) independent security and admission gates remain separate. Failing-after-merge checks are **postmerge hazards**, not retroactive premerge required failures.
