# How to start ChatGPT Project: JADE_TEMPLE

> **Doc** JT-09 · **Status** REFERENCE · **Release** UNNAMED (owner sets SemVer) · **Admission** `MERGE_ADMISSION=HOLD` · **Updated** 2026-10-31

The assistant cannot create a ChatGPT Projects workspace through the available tools. In ChatGPT, create a new Project named **JADE_TEMPLE**, copy/paste `01_PROJECT_INSTRUCTIONS.md` into the Project instructions, and upload the lightweight bootstrap ZIP or selected files `00_START_HERE.md`, `DROPIN_NEXT_CHAT.md`, `data/SOURCE_REGISTRY.json`, `data/JADE_STATE.json`. Open `site/index.html` locally if a dashboard preview is needed.

In each next chat paste only: `JADE_TEMPLE: CP.RESUME — follow project instructions and DROPIN_NEXT_CHAT.md; refresh 21 heads, blocker gates and hosted Pages before the next disjoint G3P wave.`

If a Mission Control draft PR has been created, prefer the stable PR/repository path in `DROPIN_NEXT_CHAT.md` over file uploads. A clean handoff includes exact branch/head, source IDs, verified results, existing red blockers, changed paths, artifact receipt, next action and explicit `MERGE_ADMISSION=HOLD` until controls pass.
