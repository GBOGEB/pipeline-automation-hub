When the mode switches

Escalate · EVERRED → Code Purple

E1a P0 root has a red control-plane probe (gate absent; merges admitted ungated)
E2a Code Purple case for the repo is open and not lifted
E3the owner declares (merge stall, reviewer outage, same red on most open PRs)

Hand off · Code Purple → EVERRED

H1all lift criteria met; close-out filed
H2every red seen during the case has a root ID or an alias in everred/roots.yaml
H3work items that are steady burndown (coverage floor, debt cohorts) move to EVERRED lanes while the case stays open
