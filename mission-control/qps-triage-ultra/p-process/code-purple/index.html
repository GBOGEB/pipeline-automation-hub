      4 · Recursive SIPOC
      
  
      
    
      A standard SIPOC runs once, left to right. With .self, the customer of iteration N becomes the supplier of iteration N+1, and the next input is a governed reconciliation, not a concatenation.
      
  
      
  
      
    
      

    
      
    
      
      
      
        
      State transition
      
        
      IN+1 = ON ⊕ ΔEN ⊕ CN+1
      
        
      
          
      ONLast output: receipts, check states, ranked findings.
      
          
      ΔENNewly observed evidence: completed checks, runner behaviour, new findings.
      
          
      CN+1Newly applicable constraints: gates, policies, review rules.
      
          
      ⊕Governed reconciliation. Superseded evidence is retired, conflicts go to HOLD, nothing is appended blindly.
      
        
      
      
      
      
      
        
      Confidence is not admission
      
        
      A passing local preflight raises confidence for the next iteration. Only exact-head GitHub checks and reviews move a PR through the admission gate.
