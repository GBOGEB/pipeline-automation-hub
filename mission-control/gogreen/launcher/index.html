Operational tools

    
Everyday PowerShell 7 commands, run from the clone root. Each one reads only, unless the card says otherwise. Every gh call runs with GITHUB_TOKEN/GH_TOKEN stripped, so the keyring login is used (REX-011).

    

      
Draft PR pass

        
Lists every open draft PR with its class: LIVE, THREAD-P1, CONFLICT, RED, OUTDATED, THREAD or CLEAN. Shows unresolved Codex, Copilot and CodeQL threads with priority. Never pushes, comments or resolves.

        
pwsh -NoProfile -File tools\workstation\Invoke-DraftPrPass.ps1 -ShowThreads

        
One repo, ready PRs too:

        
pwsh -NoProfile -File tools\workstation\Invoke-DraftPrPass.ps1 -Repo pipeline-automation-hub -IncludeReady

      

      
Workspace audit

        
Finds stale tokens, unpushed branches (PUSH-ME) and removable worktrees. -Apply removes clean, landed worktrees only.

        
pwsh -NoProfile -File tools\workstation\Invoke-WorkspaceAudit.ps1

      

      
Pinned outputs

        
After any change to a DAG-pinned file, commit the change, then regenerate in order and commit the outputs (REX-008).

        
python mission-control\jade_temple\tools\regen.py --write

        
python mission-control\jade_temple\tools\regen.py --check

      

      
Before you touch a PR branch

        
The main checkout fetches master only. Ask the remote for the branch head, and leave the PR alone if another session is live on it (REX-009).

        
Remove-Item Env:GITHUB_TOKEN,Env:GH_TOKEN -ErrorAction SilentlyContinue; git fetch origin <branch>; gh pr view <N> --json headRefOid,updatedAt

        
python scripts\preflight_overlap.py <terms>
