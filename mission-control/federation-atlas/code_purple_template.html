Schema hierarchy

Source: JSON Schema 2020-12 files in mission-control/federation-atlas/schemas/ and the existing Mission Control schemas (FLEET_TELEMETRY_SCHEMA.json, MC_MISSION_TELEMETRY_CONTRACT_v1.json).

Executed by: Python validators in CI (code_purple_series.validate), REX exit codes 0 / 1 / 2.

Derived, if ever needed: TypeScript types or zod schemas generated from the JSON Schema. app/package.json declares zod but no hub source imports it, so there is no second contract today. A hand-written zod schema would compete with the source; a generated one complements it.

Config formats: the hub has no .toml, .ini or pyproject files. YAML is used for the atlas graph and federation records.
