## Five independent maturity stages

1. **Descriptive** — `mip_source_consumer.py` verifies a byte-digest claimed
   source projection, workflow/job/queue and first-red exact denominators,
   retaining original artifact authentication as unproven. Native run attempts
   must be explicitly supplied and are deduplicated by the series consumer.
2. **Comparative** — `mip_maturity_series.py` requires adjacent ordered waves,
   terminal matched workflow sets, exact test-selection and runner-matrix
   digests, scoped coverage configuration, and native-only job queue clocks
   (minimum 20 measured jobs each) before emitting descriptive percentage-point
   or queue p95 deltas. Changed denominators or fallback timing return null,
   not a manufactured improvement.
3. **Inferential** — the statistical design gate distinguishes truly independent
   sample units from correlated runs/jobs/steps; a caller-provided boolean is
   at most eligibility for provider review, not evidence authentication.
   Wilson two-sided fixed-horizon 90/95/99% reference bands come exclusively
   from pinned `gg_MATH/kernels/stats_core.py`.
4. **Multivariate** — an exact-commit verified gg_MATH checkout supplies PCA,
   parallel analysis, seeded loading stability, temporal alignment,
   Bradley–Terry connected-graph finite-MLE fit/90-95-99 uncertainty and
   one-way ANOVA F/eta-squared. A governed MANOVA runtime provider does not
   yet exist and is explicitly HOLD (no Wilks/Pillai/p-value invented).
5. **Predictive** — an issued N+1/N+2 forecast stores issuing wave/SHA,
   actual timestamp, method and prediction before target observed. Persistence
   is the first bounded estimator. Scores are signed error, MAE and RMSE on
   matched terminal observation cohorts only. Unissued proposals are not
   retrospectively scored or promoted into authenticated immutable records.

## Numerator / denominator and uncertainty accounting

| Signal | Numerator | Denominator | Validity gate |
|---|---|---|---|
| Workflow rate | workflow successes | selected terminal workflow population | terminal and exact selection |
| First-red attribution | attributed terminal red jobs | all terminal red jobs | native IDs and unique first-red signatures |
| Signature compression | repeated manifestations beyond unique signatures | all first-red manifestations | descriptive correlation only |
| Queue native provenance | jobs with job-created clock | all measured queued jobs | fallback excluded from cross-wave p95 |
| Line coverage | instrumented covered lines | instrumented eligible lines | scope, tool and config equal |
| Branch coverage | covered arcs | measured eligible arcs | same config/source population |
| Independent trial fraction | authenticated independent units | declared trial population | external qualification required; UNKNOWN now |
| Forecast calibration | past preissued forecasts scored | target waves with matched actuals | independent temporal clock and immutable external ledger |

**No double counting.** A scanner occurrence, native workflow, job, step,
root manifestation and causal BD/LDAB root are different units; add neither
their numerators nor denominators. `p/n`, covariance rank, eigengaps,
PCA sign/assignment alignment, BT graph connectivity, ANOVA residual structure
and sampling independence must be checked before formal inference.
