CI health: EVERRED, red ↔ green, checks, DAG / SIPOC and OIDs

Three lenses, all on the PAH owners. Default branch: each check's class from the EVERRED red-trace ledger (red_trace.classify(), cicd_dag.everred_metrics()), weighted by the check's test jobs in DevOps census N11. PR head: the checks on each PR's last commit, with always-red policy gates set apart. Combined: GitHub's single combined state per commit, gates included (the strictest and most pessimistic view).
