# CODE PURPLE M2 user pages

Twelve tracked HTML views: `index.html`, `federation.html`, `runtime.html`, `pipeline.html`, `burndown.html`, `handover.html` and six `repo-*.html` files. All are generated from `mission-control/federation-atlas/m2_session/M2_STATE.json`. Offline inspection is supported; there is no live GitHub API fetch, token, CI dispatcher or backend side effect. Native CI produces the exact-head `M2_RECEIPT.json` with file SHA256 hashes within the existing Method Atlas artifact.
