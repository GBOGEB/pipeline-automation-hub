## How to comment on a particular UI element, without a screenshot

Use `index.html`, `cards.html` or `deck.html`, enable **DevOps hooks: ON** at the top, then click **Comment / copy** on a card, plot, diagram node, DOD row, BD leaf or slide. A client-side dialog provides a stable `CP-W18/<view>/<element>` location ID, frozen SHA-256, relative deep link, primary source/evidence and parent root lineage. Enter the observation, expected outcome and next verifiable action. Select the intended GBOGEB GitHub issue, click **Copy GitHub comment**, then **Open target issue** and paste. The file does **not** send, save or publish a comment. Do not paste credentials or A10-restricted content.

Examples:
- Dashboard evidence panel: `index.html#overview@panel-evidence-and-classification`
- Canonical actionable register: `cards.html#bd-register`
- P0 security leaf: `cards.html#BD-W18-01`
- Deep-linked DOD verification: `index.html#dod@DOD-06`
- Recursive handover: `index.html#recursiveFocus@authority-2`
- Chart: `index.html#overview@figure-two-point-issue-count`
- Briefing slide: `deck.html#slide-04`

`locator_index.json` lists the supported IDs and link routes. When GitHub Pages has *actually* been published and verified, the browser URL will also become a shareable deep link; until then use the repo's PR #670, file/element ID and source digest. No screenshot is required.
